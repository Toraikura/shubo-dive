# SHUBO DIVE — 初版の仕様

2026-09-16 / 独立したローカル制作版。育成版 `shubo-world` とはゲーム本体・保存キー・プレビューを分離。

## 遊びの一周

1. 母港から出撃。左スティックまたはWASD・矢印で自由移動。
2. 各エリアで酵母3体を救出し、侵入菌の撃退数を達成する。
3. 光のゲートへ入る。1・2エリアの終わりで、その出撃中の装備を選ぶ。
4. 最終エリアの2段階ボスを撃破し、帰還ゲートへ。
5. 結果・救出数・素材・ランクを表示。素材で機体を強化し、再出撃。

撃墜時も、その時点の戦果に応じた素材を確定して母港へ戻る。中断は一時停止メニューから可能。途中データは同じ端末・同じブラウザへ保存し、復元時は止まった状態から再開する。不在中の進行はない。

## 3つの海域

| エリア | 配色・地形 | 目標 |
| --- | --- | --- |
| 米の群島 | 青緑の水、米の島、枝分かれした菌糸 | 酵母3体・撃退6体 |
| 麹の峡谷 | 琥珀色、米の障害物、金色の胞子 | 酵母3体・撃退9体 |
| 菌糸の深域 | 紫の霧、菌糸の群れ | 酵母3体・撃退11体・ボス・帰還 |

各出撃のシードと海域番号から地形を生成する。高度は自動で調整し、操縦は水平面に集中する。無限宇宙・惑星への着陸・徒歩モードは、この初版の仕様に含めない。

## 操縦と戦闘

- 移動：WASD / 矢印 / 左のタッチスティック。
- 射撃：近い敵を自動照準。敵をタップすると指定対象を狙う。
- ブースト：Space / 右ボタン。短い高速移動と一時的な無敵。再使用待ちあり。
- 衝撃波：E / 右ボタン。近くの敵へダメージを与え、敵弾を消す。
- 一時停止：Esc / P / 上部の停止ボタン。画面を離れる時も停止。
- 追尾型、予告して突進する型、拡散弾を撃つ型の3種類。
- 最終ボスは、前半の扇状弾、後半の放射弾と予告付き突進。
- 救出には対象の近くで約1秒滞在。付近の敵を先に撃退する。
- 連続撃退で最大8倍のコンボ。救出・拾得物・エリア突破にも得点。

## 強化

出撃中の選択：連射、装甲・回復、衝撃波強化。エリア突破で一つ選ぶ。

恒久強化：耐圧フレーム、パルス発振器、循環エンジン。各3段階。次の新しい出撃から反映。結果の素材付与は一度だけ。

## 端末と負荷

- 配布物は `dist/index.html` 一枚。HTML/CSS/JavaScript/形状/シェーダーを全て内蔵。
- 実行時の画像、フォント、ライブラリ、API呼び出し、分析通信なし。
- WebGL 1 + ANGLE_instanced_arrays。3種類の基本形状を使い回す。
- 敵12体、弾96発、拾得物32個、演出24個を上限とする。
- 描画解像度の倍率は軽量1、標準1.25、精細1.6を上限とする。
- 低画質は描画頻度も約30fpsに制限する。これは描画スケジュールの上限で、実測性能の保証ではない。
- 停止中のメニューは描画間隔を延ばし、非表示のタブでは進行と描画を止める。
- アニメーション初期ON。動きを抑える設定と端末の reduced-motion に対応。OFFでも戦闘と移動は継続する。
- WebGLまたはインスタンシング非対応時は、同じゲーム状態を軽量2D投影で表示する。
- WebGLコンテキスト消失時は停止し、復帰後に描画資源を作り直す。

## 保存

保存キーは `shubo.dive.v1`。育成版・SHUBO RUNの保存は読み書きしない。

進行中は約5秒ごと、開始・停止・強化・帰還などの節目、画面離脱時に保存。入力形式と配列の上限を検査する。保存が禁止された環境では通知し、その場のゲームは継続する。ブラウザの保存領域を消すと記録も消える。

## 生物表現

酒母・米・麹・酵母を題材にしたフィクション。実在する菌を一律の悪役としない。赤い表示、突進、射撃、捕獲装置、酵母が船に追従する動作はゲーム上の表現。実際の培養・衛生管理・醸造条件の手順ではない。
