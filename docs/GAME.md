# SHUBO DIVE — 3D FLIGHT v2 仕様

2026-09-18 / ローカル制作版。育成版 `shubo-world` とゲーム本体・保存キー・プレビューを分離。

## 体験

探索艇を背後から見る追従カメラで、米の壁・菌糸の橋・浮遊する酵母の間を飛ぶ。機体の向きは左右旋回と上下のピッチで決まり、向いた方向へ自動前進する。上下移動は実際のゲーム座標に反映される。画面を横切る飾りだけの奥行きにはしない。

プレイヤー、敵、弾、拾得物、救出地点、ゲート、地形をXYZ空間で計算。救出・被弾・衝撃波の距離にも高さを含む。米は回転した楕円体として衝突判定し、船と敵を表面に沿わせる。弾は移動区間の最初の接触先に当たり、背後の壁が手前の敵への命中を打ち消さない。

カメラは機体の後方11、縦画面20の距離を基本とする。米の壁が挟まると手前へ寄せる。水平線は保ち、操作に伴う機体の傾きは演出のみ。カメラ振動・急な視野角変化は加えない。単位はゲーム用の相対値。

## 一周の流れ

1. 母港の **START** から出撃。
2. 各海域で酵母3体を救出し、必要数の侵入菌を撃退。
3. 開いたゲートへ飛ぶ。第1・第2海域の出口で装備を一つ選ぶ。
4. 最終海域の2形態ボスを撃破し、帰還ゲートへ。
5. 結果・救出数・素材・ランクを表示。素材で機体を強化して再出撃。

撃墜時も、その時点の戦果に応じて素材を確定する。途中データは同じ端末・ブラウザに保存し、復元時は停止状態で母港を表示。不在中の進行はない。

## 海域

| 海域 | 空間 | 目標 |
| --- | --- | --- |
| 米の群島 | 青緑の水、巨大な米の島 | 酵母3体・撃退6体 |
| 麹の峡谷 | 米の間を横断する菌糸、上下に分かれた信号 | 酵母3体・撃退9体 |
| 菌糸の深域 | 紫の霧、上方の救難信号 | 酵母3体・撃退11体・ボス・帰還 |

海域ごとに救出高度と配色を変更。大きな航路は一貫させ、出撃シードで周囲の米・菌糸・群体の細部を生成する。プレイ範囲には外周と高度の上限がある。

## 操縦・戦闘

- 左スティック：左右旋回、上下で機首を上げ下げ。PCではA/D・W/Sまたは矢印。
- 画面ドラッグでも機首を向ける。スティックと能力ボタンの同時操作に対応。
- 自動前進。停止 / 前進ボタンまたはBで切替。Shiftを押している間も停止。停止中も機首を変えられる。
- 自動射撃：前方の円錐内・距離50以内・米の遮蔽がない敵を選ぶ。敵タップで優先目標を指定。背後への射撃はしない。
- ブースト：Space / 右ボタン。短い高速飛行と一時無敵。再使用待ちあり。
- 衝撃波：E / 右ボタン。周囲の敵にダメージ、敵弾を除去。
- 一時停止：Esc / P / 右上ボタン。タブ非表示やフォーカスを離れた時も停止する。
- 敵：追尾、突進予告、拡散弾の3種類。ボスは前半の扇状弾、後半の立体的な拡散弾と突進。
- 酵母に距離7以内で0.75秒留まり、周辺の敵がいなければ救出。
- 信号の矢印、上方/下方表示、距離、方位レーダー、高度とピッチで目的地を案内。
- 連続撃退は最大8倍コンボ。救出・拾得物・ゲートにも得点。

## 強化

出撃中：連射、装甲・回復、衝撃波強化から選択。

恒久強化：最大耐久、射撃威力・間隔、ブースト再使用時間。各3段階で、次の新しい出撃から反映。結果の素材付与は一度だけ。

## 表現と負荷

- 配布物は `dist/index.html` 一枚。HTML/CSS/JavaScript/メッシュ/テクスチャ/シェーダーを内蔵。
- 外部画像、フォント、ライブラリ、API、分析通信なし。
- 米は凹凸を持つメッシュと、256×256の手続き生成した穴の陰影テクスチャ。三方向から表面に投影する。
- 白い菌糸と放射状の胞子、紫の出芽酵母、金色の粒子、コーラル色の桿菌、象牙色の探索艇。
- 距離に応じた水中の霧、光の筋、水面の光の揺らぎ、深度テスト付き浮遊粒子、低解像度の発光合成。
- WebGL 1。拡張があれば形状をまとめて描画。拡張がない場合も3Dで、軽量設定に落とす。
- 4種類の基本メッシュを共用。敵12体、弾96発、拾得物32個、演出24個、浮遊粒子260個が上限。軽量時は浮遊粒子120個・菌糸数を削減し、発光の合成を省く。
- 画素数は180万以下。倍率は軽量1、標準1.25、精細1.5以下。軽量描画は約30fps上限。これは実測性能を保証する値ではない。
- アニメーション初期ON。OFFと端末のreduced-motionを尊重。OFFでも戦闘と操縦は動く。
- WebGL非対応・初期化失敗時は明示的な再読み込み案内を表示。戦闘は開始しない。
- コンテキスト消失時は進行停止。復帰後に資源を再作成し、プレイヤーが再開を選べる。

## 保存・移行

保存キー `shubo.dive.v2`。旧版 `shubo.dive.v1` は読み取り用として残す。旧版の強化・記録・出撃中の達成状態を保ち、3Dの安全な入口へ配置し直す。旧版の平面上の敵と弾は引き継がない。育成版やSHUBO RUNの保存を読み書きしない。

進行中は約5秒ごと、開始・停止・強化・帰還、画面離脱時に保存。入力形式・配列上限・必須フィールド・不整合なボス状態を検査。保存禁止環境では通知し、その場のプレイを継続する。

## 生物表現

酒母・米・麹・酵母を題材にしたフィクション。菌の色、遊泳、探索艇、武器、救出はゲーム表現であり、実際の製造工程を再現するものではない。
