# 検証範囲

2026-09-16。ユーザー指定：**制作とコード検証まで。ブラウザ操作は行わない。**

## 実施

- `python3 build.py`：正本のソースを単体HTMLへ結合。
- `node --check src/core.js` / `renderer.js` / `app.js`：JavaScript構文。
- `node tests/verify.cjs`：実際のゲーム処理をNodeで実行。
  - 3シードで通常難易度の開始から、3エリア、強化選択、全9体救出、ボス撃破、帰還まで連続シミュレーション。
  - この完走では、進行中の位置・耐久・敵HPを強制変更しない。入力は移動、ブースト、衝撃波のみ。初期の経路探索と弾の回避判断はテスト用自動操縦。
  - 放置時の敗北、ダメージ後の無敵、射撃、衝撃波、再使用待ち、救出条件、ステージ遷移、結果後の停止。
  - ボス撃破と同じ更新内に消された敵弾が命中しない回帰検証。
  - 保存往復、キー欠落・不正配列・不整合なステージ状態の拒否。
  - 形状の外向き法線、正のスケール、有限座標、正規化された回転、形状数・エンティティ上限。
- `node tests/app-flow.cjs`：画面要素と描画を代替したNode上のアプリ処理検証。
  - 開始、キーボード入力、一時停止、非表示タブ、途中復元、装備選択、購入、次回への反映。
  - 勝利／敗北結果、再挑戦、素材の二重付与防止、破損保存と保存禁止時の継続。
  - 設定だけで未開始のプレビューを進行中の潜航として保存しない。
- ローカル配信のHTTP応答200。

結果の数値は `verification.json` / `app-verification.json`。ビルドの識別情報は `build-info.json`。

## 計測の意味

検証シードの静的形状は約3.8〜3.9万三角形。敵・弾・演出を上限まで入れた検証構成は静的＋動的で約8.1〜8.2万三角形。これはCPU側で生成した形状の計数で、GPU時間の測定ではない。

自動操縦の完走時間は76〜82秒だった。最短に近い経路で進むコードの結果であり、人が初めて遊ぶ時の所要時間・難易度・楽しさの証明ではない。
