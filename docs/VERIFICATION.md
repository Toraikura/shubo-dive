## 検査内容

XYZ操縦、上下で異なる救出・被弾判定、前方への照準、米の遮蔽、弾の接触順、ボス撃破と同時の敵弾除去、追従カメラ、形状の外向き法線・頂点順、保存往復・旧版移行・壊れた保存の拒否を検査。

アプリ処理では開始、キーボード・ドラッグ・停止ボタン、一時停止、非表示タブ、装備選択・購入、素材二重付与の防止、勝利・敗北・再挑戦、保存禁止時の継続を検査。自動画質は初期ONとOFF設定の保存・復元を検査。

軽量化専用の検査では、ゲームcoreの非変更、以前と同じ物体の動き、輪の厚み、画面内の頂点がある形状を落とさない境界判定、LOD切替の余裕、配列再利用、単発の遅延を無視する制御、持続負荷時の下限、余裕が戻った時の回復、フレーム制限などで改善しない試行の取り消しを検査。

WebGL代替実装では、型付き配列の使用数と容量、`bufferSubData`の範囲、テクスチャ読み書き先、画面サイズ変更後の資源数、低画質の作業領域解放、コンテキスト復帰時の再作成を検査。GLSLコンパイルや画像を検証するものではない。

## キャンペーン

通常難易度・恒久強化なし、海域間で装甲を2回選択。seed 941 / 1842 / 3091は全9体救出・2形態ボス撃破・帰還まで成功。ゲーム内時間は100.65 / 97.30 / 99.20秒。位置やHPの強制変更は使わない。

自動操縦は全座標を参照するため、人の難易度・楽しさ・所要時間の証明ではない。

## 描画負荷

詳細は `PERFORMANCE.md`。開始時構成の送出三角形は約19万→約7.5万、標準画質の合成36視点平均は約20.5万→約2.7万。これらはCPU上の計数で、GPU時間やFPSの測定ではない。

単体HTMLは約105KB。ファイルが小さいことと、端末での処理が軽いことは区別する。
